# Expected paths of selected methods of conformance/probe/src/probe/Probe.java.
#
# The conditions, the order of the effects and the exits are derived by hand from the Java semantics (a guard clause puts
# the rest of the method under the negated condition, a case that falls through shares the next body, finally runs on
# every way out). Expression text is as Spoon prints it, with package qualifiers dropped.
#
# Format: a method name, then one row per path:  <number> | <when> | <then, in order, or -> | <how it ends>
# <how it ends> is FALL (reaches the end of the method), RETURN <value> or THROW <value>.
